# EDU ROBOTICS

Қазақ тіліндегі робототехника зертханасы. GitHub Pages арқылы жариялауға арналған статикалық сайт.

## GitHub Pages-ке жариялау

1. GitHub-та жаңа repository ашып, оған `edu-robotics-site` бумасының ішіндегі `index.html` файлын жүктеңіз (репозиторий түбірт жолдодан).
2. Repository → **Settings → Pages** бөліміне кіріңіз.
3. **Deploy from a branch** таңдаңыз, `main` тармағы мен `/ (root)` қалтасын көрсетіп, сақтаңыз.
4. Pages көрсеткен мекенжайды ашыңыз. Алғашқы жариялау біраз уақыт алуы мүмкін.

Сайттың негізгі құрылымы бір HTML файлда орналасқан. Blockly, Three.js және Supabase кітапханалары CDN-нен жүктеледі; толық интерактив үшін ашылған құрылғыда интернет болуы керек.
